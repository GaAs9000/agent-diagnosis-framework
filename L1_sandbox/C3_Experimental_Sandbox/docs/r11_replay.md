# R1.1 fixed replay selection and dispatch provenance

`r1.r11_replay.select_checkpoint(baseline, kind, max_turns=10)` returns a selection containing `reference`, `checkpoint_id`, `remaining_turns`, and its fixed `reason`, or `None`. S requires a real, valid, officially complete baseline and selects the first qualified completed tool boundary with remaining turns. T scans actual tool-result events in original order, then selects the nearest qualified completed boundary preceding the earliest subsequent model tool call. Multiple calls in one assistant batch do not create intermediate cold boundaries. Source messages must pair all native IDs; source audit must be qualified; checkpoint registration must contain no rejection reasons. Lack of real admission is expected at this selection stage.

`select_engineering_candidates(results)` returns `S_candidate`, `T_candidate`, and all per-task `decisions` in input order. This selection provides engineering coverage only. It neither changes success criteria nor supports comparative method claims.

`admit_checkpoint(baseline, reference, root, model_trace)` requires a fresh output directory. Before Docker starts, the raw qualification log's SHA-256 must equal `model_qualification.model_trace_sha256`. A fresh container reconstructs the full supported filesystem, verifies paths, bytes, types and permissions, audits its process/tmp/isolation state, and recomputes system identity using its observed environment. Exact paired messages and runtime must match the registered checkpoint. The existing private admission authority binds the raw evidence into a receipt. The returned mapping contains `qualification`, `receipt_identity`, `paths`, `replay`, and `authority`; the latter two are live controller objects and are not JSON artifacts. This function performs no model continuation.

Baseline and branch execution pass `DispatchRecorder` as NativeAgent's async `dispatch_callback`. Every newly dispatched model call has exclusive before/after full snapshot files and a `dispatch.json` mapping native call ID to code SHA-256, actual result/error, and filesystem delta (path, type, mode, hash and byte length). Unsupported symlinks/hardlinks/special files make snapshot evidence ineligible and preserve the dispatch result. Container invalidation, timeout and unrecognized infrastructure errors fail closed. An audited persistent process or temporary file makes a checkpoint ineligible without changing the original model result. Invalid execution leaves task-completion, target and regression claims unknown (`None`).

Synthetic tests cover multi-call batch selection, rejection of altered message prefixes, first-candidate ordering with all decisions retained, raw trace hash drift before Docker, path deletion/creation/mode deltas, unsupported snapshots, and invalidated runtime handling. Real Docker and LLM execution belongs to the root controller.
