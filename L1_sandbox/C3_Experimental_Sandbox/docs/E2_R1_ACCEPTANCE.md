## 探针与信息边界

探针只使用同一检查点公开文件的聚合结构计数，以及前次真实工具执行的退出码、输出字节数和文件变更数。没有目标对象路径、文本答案、正确线宽、rubric、补丁或成功轨迹。固定检查器在 Agent 容器内只读采集；采集前后文件树一致，临时目录为空，无遗留进程。

探针作为明确标注的运行时补充观测，插入原始前缀之后。Target 和 Matched 字节长度相等，真实分词器及完整消息封装 Token 数相等；无额外执行回合、无采样参数变更。公开统计、注意力和提示长度可能共同影响行为，因此不能将探针视作“纯机制”，也不假定匹配对照行为无影响。

实际运行发现并修复了两个合成测试未覆盖的问题，全部发生在分支模型调用之前：

1. 原填充策略不能在 Qwen 分词器上匹配 Token，已失败关闭；改为有界填充搜索并核验完整输入。
2. 8 MiB XML 读取上限误用于 12 MiB 嵌入字体，导致有效 DOCX 被标为解析错误；改为仅限制实际解析的 XML，整个压缩包继续保留大小、成员数和压缩比上限。

首版 `probe-audit` 保留作为失败记录；只有重新实际采集、核验通过的 `probe-audit-v2` 被纳入封存分支身份。

## 调度与成本

两个方法客户端是固定的工程验收驱动器，预测均为 0.5；它们不代表已实现的 D6/D7 诊断方法。每轮先封存完整候选预测，再查询、扣费、揭示。A 购买四个探索结果；B 购买同一个 Original 缓存结果。物理执行共享，观察历史为 A=4、B=1。

- 逻辑探索查询：5 次，A 支付 4、B 支付 1。
- 物理执行：8 次，探索 4、封存确认 4；共享 Original 只执行一次。
- 八分支计量：输入 12,180 Token，输出 536 Token；合计墙钟 62.782 秒；控制器准备、环境及评分 28.782 秒。后者排除模型等待，但包含准备和分词计数，不等同于纯容器 CPU 时间。
- GPU 秒未测，记为 `null`，没有用 0 替代。
- 原始任务和原生资格检查的成本单独保留。包含资格检查在内，共有 17 次完成的真实模型响应：资格检查 6、原始任务 3、分支 8；累计已记录输入 15,540、输出 2,041 Token。另有两次未完成的资格请求，不能按已测零成本算入。
- 模型下载、镜像构建和适配开发是设置成本，不纳入算法查询预算；本轮不报告算法效率优势。

## 恢复和信任范围

支持无待处理工具调用、无持久后台进程、临时目录为空的冷边界。覆盖完整工作目录、精确消息、明确配置、镜像、模型和 tokenizer 身份。检查模型服务启动参数与监听进程，确认禁用 prompt cache、并发为 1；分支前另查磁盘与 tokenizer 指纹。

时间、PID、namespace ID、文件时间戳、hostname、模型 KV cache 不恢复；这些状态不在本轮支持合同内。HMAC 将准入绑定到实际证据，但宿主控制器仍是可信方，不提供对恶意宿主的密码学实验真实性保证。方法权限通过窄 API 验证；没有声称同一个 Python 进程能够隔离恶意自省代码。实际执行 Agent 与评分器分属无网络、无宿主挂载、只读根文件系统的容器。

四项实际负例证明：隐藏评分器／宿主私有文件／Docker socket 不可读、根文件系统不可写；符号链接导出被拒；后台进程和 `/tmp` 缓存导致资格拒绝。这不是对所有内核逃逸的证明。

本任务启动的模型与 tokenizer 服务已停止，端口已释放；临时容器已清理，模型权重、镜像和全部证据保留。
