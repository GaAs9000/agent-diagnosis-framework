# L2 统计执行口径决定（2026-10-16）

## 本轮决定

| 项目 | 采用的口径 |
|---|---|
| D1 | 保留 `code_v0_upper`，初始价值上界使用 `0.2α`，下降检验使用 `0.8α`，单回合比较继续作现有校正 |
| F21 | 选择方案 1：保留当前全部数值逻辑，仅对齐注释与说明；不采用 `both_const`、`either_const` 或单侧混合方案 |
| 正式默认 | 保留 `N1=12, N2=24, stride=4`；不改成8/16，也不因此自动启动正式付费批次 |

当前有界连续两样本下界统一取 `min(bootstrap_lb, newcombe_style_lb)`，连续单样本终点统一取 `min(bootstrap_lb, wilson_lb - Y)`，不只处理零方差样本。观测值均为0/1时继续走二元分支，确定性终点的处理不变。F21按“保留算法、澄清现行合同”处置，不宣称修复了060的集中下降漏检。

D4解释份额分母仍未决定，保持现行公式。历史设计快照和付费产物保留；此决定应在下一次统一发布设计版本时纳入，不改写历史运行合同。

## 为什么保留当前组合

配对校准比旧模拟覆盖了更多位置、二元观测、零膨胀和完整F21×D1组合。在保存的JSON中，各N下零假设场景的最大**观测**集中误报率为：

| N1／N2 | current＋upper | either_const＋upper |
|---|---:|---:|
| 4／8 | 3.7% | 7.0% |
| 8／16 | 2.6% | 4.3% |
| 12／24 | 2.6% | 4.8% |

当前组合是更保守的运行默认；放宽连续下界虽可能提高灵敏度，但尚不足以作为本轮正式替换。点估计D1在多个所测场景下出现更高误报，本轮不采用。这是执行选择，**不是证明上界方案对所有分布都充分控制错误率，也不是证明其他方法不可能有效**。

12／24的价值取决于效应与分布：保留当前组合时，名义大跌幅 `.55` 的中段／晚段精确轮次检出率为95.0%／96.1%；但二元场景只有82.0%，较小跌幅 `.45` 为73.8%，低起点 `.43`、跌幅 `.40` 为61.1%。不能宣称正式配置普遍有90%或95%的定位功效；小效应或更难分布仍可能无检出。

多步变化场景中，报告命中任一真实变化轮次不等于发现唯一致命轮次；当每个变化轮次自身达到单回合判据时，将其中一轮判为集中也不自动构成错误。区间重叠和精确定位须分开报告。

## 校准证据的边界

机器输出位于本机 `validation/m3_dev_mini_review_20261016/stat_review/f21_d1_n_calibration.json`（SHA-256 `24b1f920e04d522b07809cbc9007d43b9d6c53d5afc95725519922257c626e67`）。实际为4种生成分布、9种零假设参数场景×3档N，共27个H0格；14种备择场景×3档N，共42个H1格；每格1000次，评估10种组合。

必须保留以下限定：

- **近似引擎而非精确生产实现。**校准使用500次bootstrap和共享随机状态；生产使用2000次、由样本摘要与alpha决定的seed。主要公式与选择流程一致，但结果并非逐样本相同，后续高精度确认应直接调用生产实现或验证等价性。
- **有限蒙特卡洛不等于严格5%保证。**48/1000的逐格Wilson 95%区间约为3.64%–6.31%；43/1000约为3.21%–5.74%。选过多个场景／方法的整体保证更不能由点估计直接推出。
- **覆盖应以实际代码为准。**未实现首部注释声称的经验残差bootstrap；中等方差分布是精确保均值的离散混合，并非Beta-binomial。H0均为固定 `T=35,Y=0` 的均匀线性衰减。
- **生成器理论均值与抽样误差分开。**离散混合与hurdle构造保持理论均值；保存的20000次抽样检查最大均值误差为0.0068，原摘要“≤0.003”不准确，但不否定理论构造。
- **随机种子尚不完全可重现。**场景使用Python内置 `hash()`，未保存实际整数seed或 `PYTHONHASHSEED`；跨进程通常不同。10种方法在同一份数据上的配对关系有效，但只保存汇总，无法据此复原逐试验配对差值。
- **粗指标不是精确定位。**`contains_true=any(...)` 只要求选中区间重叠至少一个真实变化轮次，不要求完整覆盖多步事件；粗集中指标还可能包含区间重叠但报错轮次的结果。

这些限制不要求为本轮保留现行算法而重跑历史分支。它们限制的是校准报告可作出的统计承诺。`either_const` 可作为后续预先声明的候选比较，不改变当前执行默认。
