## G2 为什么尚未通过

102次调用为74次首执行加28次诊断复执行，每批最多两次、并发1，均在原六小时窗口及6,300次硬上限内；其中101次为实际工具执行，1次为原生参数错误反馈。没有为通过而重放到匹配，也没有换 Actor 样本。

应用已单列的4条 input-directory `ls` 分类修正后，结果为：56条精确、24条已声明运行时变异、22条仍不满足冻结分类器。6条已声明的状态字节差异为 DOCX ZIP 时间戳；不将它们说成完整文件字节相同。

对剩余22条做了独立只读取证：

- 20条来自 `ls`：mtime不同，其中6条还有目录 `total` 分配块数不同。
- 2条来自同一 pip 失败调用的两次重放：仅3处 `HTTPSConnection` 对象 repr 内存地址不同。
- 这22条的原始/回放工作区 blobs、文件列表、目录及权限均精确一致；除上述字段外，完整 observation 一致。原始输出字节仍然不同。

取证解释不等于预注册豁免。保留 `blocked_unexplained_difference` 与旧比较原件，不事后放宽 allowlist。特别是 `ls total` 是分配块数，原快照没有记录该物理属性；对象地址也是进程局部状态。不能从文件内容哈希倒推出这些值，也不能据此声称模型后续响应分布相同。
