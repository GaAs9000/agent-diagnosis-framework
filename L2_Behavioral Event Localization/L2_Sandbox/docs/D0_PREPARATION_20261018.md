## 实现与统计含义

`v05.py` 增加显式的 `conditional_frozen_dev_pool` 目标；旧 `family_population` 入口保留。每一方向都在同一选择半集上选逐单元策略与最佳固定策略，在另一半集评估，再交换。目标是两个方向各自条件收益的平均，不是同时条件于两个半集的总体收益。逐项结果按实际物理分支包和端点合并系数，避免把共享结果误当独立观测；发现物理包跨选择／评估复用时拒绝计算。

区间组合有界 Hoeffding 与独立、非同分布经验 Bernstein 界，每个目标按两方向、两尾、两方法分配 α/8。经验零方差仍保留范围项；只有两策略完全相同、系数代数消去时才报告精确零。加权主目标与不加权辅助目标分别有覆盖口径，不声称联合覆盖。实际独立续跑是统计假设，封签本身不能证明随机独立。

经验 Bernstein 依据 [Maurer–Pontil 2009，Theorem 11](https://www.cs.mcgill.ca/~colt2009/papers/012.pdf)。二项分辨率按 [NIST 精确二项区间](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbici.htm)反演。

D1 执行器实际使用至多 3 个并发客户端；共享、原子落盘的准入账本在每一次 HTTP 重试前扣限额。到限停止新准入，收齐已经准入的回执。生产 D1 与条件 D2 均重新核对冻结的测量门禁记录；模拟输出不能替代真实测量证据。
