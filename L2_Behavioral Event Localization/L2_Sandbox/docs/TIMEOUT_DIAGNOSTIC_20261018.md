- 使用保存的同一 `r000007/request.json`，原始请求和配置均绑定 SHA-256；通过生产 `canonical` 序列化恢复同一发送负载。
- 保留 Qwen3.6、temperature=1、max_tokens=8192、无 seed、原 tools、原非流式模式与原 Mac→SSH→8001 路由。唯一新条件是本次原生传输调用的600秒超时参数；原配置文件仍为300秒，原110个执行文件不变。
- 必须等待整个串行批次及可能启动的G2结束，确认 running=0 且 waiting=0；服务安全停止线前至少剩645秒，否则不发送、不续租。
- 只调用一次 `OpenAICompatibleBackend.send`，没有外层重试；发送前以独占、落盘的 marker 消耗这唯一授权。进程崩溃后也不能自动再发。
- 总HTTP预算检查包含前批93次、当前串行批次所有尝试和这一次诊断，仍不得超过3,360。
- 原始响应、HTTP元数据、用量及结束原因单独封存；只投影原始JSON，不调用工具参数解析／执行或官方评分。单次观察不构成能力或总体恢复率结论。
- 传输参数为600秒；外层执行 watchdog 对发送后的整个进程设置645秒硬边界，等待阶段也有截止时间。请求超时与进程终止均保留未知，不算成功。
