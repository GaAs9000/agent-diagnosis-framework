### 2.3 阶段 4B：“从没做对（`never`）”缺陷的规则提醒干预：区分“没发现”与“做不到”（`Y7` 深度拆解）
- **文件位置**：[`validation/v04_dev45_20261016/stage4_never_rule_summary.json`](../validation/v04_dev45_20261016/stage4_never_rule_summary.json)
- **核心发现**：由于 `never` 占总扣分的 $95\%$ 以上，我们对 4 个代表性任务的 `never` 缺陷在对应编辑轮 $k$ 注入细则提醒（`rule` 臂 vs `plain` 臂，每臂 $n=8$），实证将 `never` 清晰拆分为两类机理：
  1. **“没发现 / 规则疏漏（Oversight）”——提醒即修复**：
     - `officeval_060.requests_035.r00`（$k=17$，遗漏第 3 页幻灯片与备注）：`plain = 0.5455` $\to$ **`rule = 1.0000`**（8/8 全满分！**$\hat{\Delta} = +0.4545, p = 0.0011$**）。

  2. **“真做不到 / 能力上限（Capability Limit）”——提醒亦无效**：
     - `officeval_003.requests_035.r02`（$k=30$，复杂公文版式红头与印章排版）：`plain = 0.3333` $\to$ **`rule = 0.3333`**（**$\hat{\Delta} = 0.0000, p = 1.0000$**）。
     - `officeval_033.requests_035.r00`（$k=13$，Word 复杂流程图绘制）：`plain = 0.3529` $\to$ `rule = 0.4608`（$\hat{\Delta} = +0.1078, p = 0.5000$，统计不显著）。
