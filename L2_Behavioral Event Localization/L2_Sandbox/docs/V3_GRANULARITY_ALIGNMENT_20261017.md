## 一项完成的含义

每个 R 项单独记录：工作项 ID、来源条款、交付物、当前状态、证据、验收条件、依赖、提交号。状态分为“待实现/待修 → 进行中 → 已实现待复核 → 自动核验通过 →（条款要求时）待人工 → 已验收”。实验支持/未支持/未决另记，不能与工作状态混用。

脚本存在不等于运行完成；单测通过不等于真实实跑；自动比对不等于人工审阅；模板PASS不算证据；有摘要不等于泄漏门禁已过；启发式不算真实LLM。每个大阶段只有所有必要小项满足且有证据才能报完成。

实现/提交以 Antigravity 为主写；Codex 做独立核对和对齐记录，避免并发改同一源码或争用Git索引。用户保留研究阈值、费用/新请求、留出名单及指定人工审核的决定。研究终点源码与测试已见未提交修改，属于 R6 进行中，不可当已验收。

## 共用计数单位与命名空间

| 单位 | 统一含义／报数规则 |
|---|---|
| 任务家族／任务 | 家族用于开发／留出划分与跨任务聚合；同一任务多次运行不算多个任务或家族 |
| 父运行 | 同一冻结配置的一条完整L1轨迹；计划槽、实际尝试、有效完成和验收通过分别报数 |
