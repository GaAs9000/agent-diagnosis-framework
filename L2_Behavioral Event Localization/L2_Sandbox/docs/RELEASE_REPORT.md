# L2 v0.1.0 工程交付与实际验收报告

**日期：2026-10-13。**依据：用户确认的 `L2_Design_v0.1.md` 与实际上传的完整 L1 证据。原设计稿原样保存在 `docs/DESIGN_INPUT_v0.1.md`；本轮没有新增文献调查、创新性判断或 L3 能力画像。

## 1. 交付内容

这是独立可安装的 Python 源码工程：L1 证据适配、有限 DOCX 对象探针、只读工具视图、规则基线、单个 Analyst 循环、结构与引用校验、可移植诊断包、冻结实验计划、受限 L1 续跑桥、回执导入、基础评测函数、CLI、配置、本机验收脚本、测试及示例。

不修改用户现有 L1。命名空间为 `l2_sandbox`，命令为 `c3-l2` / `l2`。实时模型层复用已安装 L1 0.2 的 native ModelBackend；离线分析和验证不依赖 L1、Docker 或模型服务。0.1 历史兼容例外，需要已有 L1 校验器。

**当前实现名称：只读定位与假说系统，附受限实验接口。**不是“已经通过真实干预验证或研究准确率评估的系统”。

## 4. 核心负向测试

验证了：源/输出摘要篡改、JSON 重复键、NaN、路径穿越、符号链接、额外文件、错误事件/版本引用、未读事实引用、无实验提升 verdict、DOCX DTD/entity（含 UTF-16）、对象/读取/请求上限、模型原始无效输出保留、有限修复、网络异常不伪造响应、注入内容请求 shell 被拒绝、兄弟分支结果不读取、原始源不变、中文归档默认回环校验、未知终点不补零、单任务家族不能伪装独立测试。

实验计划与执行测试区分了资格、评分和源类型：父任务无提交导致官方评分 error，不直接否定可用检查点；未支持的信息干预仍 blocked；未授权分支不启动；失败尝试保留在 attempted 分母，单组原样续跑不输出 supported。

## 5. 真实 Analyst 怎样在用户本机验收

在已有 L1 0.2 的虚拟环境安装 L2 后，修改模型配置中的占位模型名，运行 `doctor`，再显式执行 `analyze --allow-model` 或 `scripts/accept_local.py --allow-model`。

此环境没有完整的新 L1 0.2 native 后端模块。实际 doctor 的结果为 ready=false，model_endpoint_contacted=false，原因是该依赖缺失，已保存原回执。没有宣称本次完成 Gemini 或本地模型的 Analyst 推理。

当前同一个 Analyst 可调用有限检索工具，再通过 `submit_diagnosis` 提交；原始请求、响应、检索内容、拒绝及修复全部保存。模型文本被结构接受后仍标 semantic_entailment 未认证。完成一次本机 M2 运行只能证明模型接线与输出过程，不直接证明 L2 研究有效。

## 6. M3 的实施边界

现在可以冻结计划、明确指出缺什么资格，并通过现有 L1 原样恢复接口执行新基线分支。**没有偷偷向 native conversation 加一条消息来冒充正规信息干预。**

两个信息模板 require L1 的明确干预接口，因此本版保持 blocked。当前控制器仅有单组基线，回执导入输出 not_identifiable，不做显著性检验，不将一次改善写成根因支持。任意对象修复、动作替换、强模型接管不在本版生产入口。

用户原计划第九节明确允许此边界：L1 只支持不变续跑时，信息干预计划保持 blocked。要完成真实局部效应验证，需要进一步实现并验收 L1 注入接口、干预审计、匹配对照和预先冻结的统计方案，不能只改状态标志。

## 7. 附带样本的可移植性与限制

九份自然源输出、一份 Analyst fixture、一份 legacy fixture、两份计划，共13份 L2 包。每份包含自己的封口索引，均可用 wheel 独立检查。

Diagnostic Package 只包含实际引用或读取的源字节，不是完整 L1 Episode。源索引和引用选择器允许独立核查这些片段；没有复制未读原始请求，不把声明的 lazy 引用当作已经完整保存的原文。需要恢复或全面重验 L1 时必须使用原完整包。

没有分发模型权重、API Key、Docker 镜像或完整上游 Benchmark。用户来源的任务/文档/轨迹仍可能有敏感内容，本轮不宣称自动脱敏。源包不执行，用户未来通过 L1 执行其官方代码仍是独立信任边界。

## 8. 完成定义

本包交付了可运行的 L2 M1/M2 工程与受限 M3 接口，不是再一份纯架构图。与此同时，不能把代码已实现、fixture 通过和九份真实记录的规则分析，合并宣传为真实 Analyst 效能或因果验证已完成。

下一道本机门槛是：用一条现有完整 L1 Episode，运行真实只读 Analyst，检查它的实际检索、结构化定位、竞争解释、弃权和原始请求。随后才讨论对照干预，不为迎合分数重写原始证据。
