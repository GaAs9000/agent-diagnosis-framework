## 本批结束后的自动处理

`scripts/finalize_d0_serial.py --execute` 是一次性后处理入口，不发送模型请求、不补跑失败槽、不扩大 G2 样本。它等待受限补采结束，把最终封签副本送入服务器新建的独立目录，然后重做 G1／G4，并使用原来的 `evaluate_r19_g2` 计算真实 G2 配对结果和家族区间。数据、源码和回传报告均绑定哈希；处理总上限七小时，子任务结束后的传输／审计／取回共用一小时预算。不同阶段不能复用旧结果。

自动报告位于 `validation/d0_20261018/serial_postprocess/`，成功标志为 `manifest.json`。失败或超时留下日志和锁，不自动重复执行。该入口不进行新的 Mac／Docker 评分；两条新父轨迹的 E1 官方复评应在其封签完成后按原环境单独补齐。
